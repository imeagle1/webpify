# WebPify

**Smaller files. Bigger freedom.**
Private, offline image converter to WebP, JPEG and PNG.

[English](README.md) · [فارسی](README.fa.md)

**iRamo.Ai | مرجع آموزشی هوش مصنوعی** by Alireza Ramezani

</div>

## Features
- 100% client-side: your images never leave your device, no tracking, works offline
- Smart target size: set a limit (for example 150 KB) and get the best quality under it
- Batch conversion: drop many files or a whole folder, paste with `Ctrl+V`
- Responsive sizes: 320 / 768 / 1280 px or a custom width, exported in one ZIP
- Live before / after comparison slider
- SEO-friendly file names (lowercase, dashes)
- Notifications, sound and auto-save when conversion finishes
- Persian (RTL) and English interface

## Download
Get `WebPify-Portable-x.y.z.exe` from the [Releases](../../releases) page and double-click it. No installation needed.

Windows SmartScreen may warn because the app is not code-signed: click **More info → Run anyway**.

## Use in the browser
Open `src/index.html` in any modern browser. It is a single file and works offline.

## Build from source
```bash
npm install
npm start        # run the app
npm run dist     # build dist/WebPify-Portable-x.y.z.exe
```
