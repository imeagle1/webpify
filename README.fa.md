## امکانات
- پردازش ۱۰۰٪ داخل دستگاه شما: هیچ تصویری آپلود نمی‌شود، ردیابی ندارد و آفلاین کار می‌کند
- حجم هدف هوشمند: سقف حجم (مثلاً ۱۵۰ کیلوبایت) را بدهید تا بهترین کیفیت زیر آن انتخاب شود
- تبدیل دسته‌ای: چند فایل یا یک پوشه کامل را رها کنید، یا با `Ctrl+V` بچسبانید
- سایزهای واکنش‌گرا: ۳۲۰ / ۷۶۸ / ۱۲۸۰ پیکسل یا عرض دلخواه، همه در یک فایل ZIP
- مقایسه زنده قبل و بعد با اسلایدر
- نام فایل مناسب سئو (حروف کوچک و خط تیره)
- اعلان، صدا و ذخیره خودکار پس از پایان تبدیل
- رابط فارسی (راست‌به‌چپ) و انگلیسی

## دانلود
فایل `WebPify-Portable-x.y.z.exe` را از صفحه [Releases](../../releases) دانلود و دوبار کلیک کنید. نیازی به نصب نیست.

اگر ویندوز (SmartScreen) هشدار داد، چون برنامه امضای دیجیتال ندارد: روی **More info** و بعد **Run anyway** بزنید.

## استفاده در مرورگر
فایل `src/index.html` را در هر مرورگر امروزی باز کنید. یک فایل تکی است و آفلاین کار می‌کند.

## ساخت از روی سورس
```bash
npm install
npm start        # اجرای برنامه
npm run dist     # ساخت فایل پرتابل در پوشه dist
```
بیشتر: [راهنمای ساخت](docs/BUILD.fa.md) · [راهنمای گیت‌هاب](docs/GITHUB-GUIDE.fa.md)
